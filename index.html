Zero. For a limited number of clients each year, we install the entire solution at NO COST. We pay 100% of the installation. No catch, no hidden fees, no monthly charges — ever.

We use industry-leading software to identify the most in-demand products — no guesswork. We also run surveys so residents and employees always have their favorites stocked.

Real-time Point of Sale software keeps our local staff informed of inventory levels so inventory is replenished regularly and on-time — every time. You'll never deal with an empty machine.
